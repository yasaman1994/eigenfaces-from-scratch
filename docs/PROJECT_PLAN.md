# برنامه اجرای پروژه Eigenfaces - تیم ۴

## هدف این سند

این سند نقشه راه سه‌روزه تیم است. هدف، ساختن یک مسیر ساده، صحیح، قابل‌آموزش و قابل‌ارائه است؛ نه نوشتن کد پیچیده.

## اصول تصمیم‌گیری

1. ابتدا کوچک‌ترین مسیر کامل را می‌سازیم.
2. هر مرحله باید ورودی، خروجی، فرمول و shape مشخص داشته باشد.
3. هیچ پارامتری از test یاد گرفته نمی‌شود.
4. ابتدا درستی را بررسی می‌کنیم و سپس نمودارها را زیباتر می‌کنیم.
5. هر نتیجه باید با عدد، نمودار یا نمونه تصویر پشتیبانی شود.
6. نوت‌بوک نهایی باید از بالا تا پایین بدون دخالت دستی اجرا شود.

## فرضیه‌های پروژه

### فرضیه عمومی

با افزایش `k`، reconstruction error نباید افزایش پیدا کند؛ ولی پس از مدتی سود اضافه‌کردن مؤلفه‌های بیشتر کم می‌شود.

### فرضیه اختصاصی تیم ۴

Euclidean distance و Cosine similarity ممکن است برای بعضی تصویرهای test نزدیک‌ترین همسایه متفاوتی انتخاب کنند. Cosine اندازه کلی بردار را حذف می‌کند، درحالی‌که Euclidean هم جهت و هم اندازه اختلاف را در نظر می‌گیرد. هنوز از پیش تعیین نمی‌کنیم کدام بهتر است و نتیجه را با آزمایش گزارش می‌کنیم.

## طراحی آزمایش

### داده و split

- برای هر شخص ۸ تصویر train و ۲ تصویر test
- انتخاب تصادفی درون هر هویت
- seed ثابت تصمیم‌گیری‌شده تیم: `42`
- mean و مؤلفه‌ها فقط از train

### مقادیر k

حداقل مقادیر الزامی:

```text
10, 50, 150
```

در صورت داشتن زمان، برای نمودار کامل‌تر:

```text
1, 5, 10, 20, 50, 100, 150, 250
```

## کنترل شکل ماتریس‌ها

اگر `n_train = 320`، `n_test = 80`، `d = 4096` و تعداد مؤلفه‌ها `k` باشد:

| متغیر | shape مورد انتظار |
|---|---|
| `X_train` | `(320, 4096)` |
| `X_test` | `(80, 4096)` |
| `mean_face` | `(4096,)` |
| `X_train_centered` | `(320, 4096)` |
| `gram_matrix` | `(320, 320)` |
| `eigenfaces` | `(4096, r)` |
| `train_codes` | `(320, k)` |
| `test_codes` | `(80, k)` |
| `X_test_reconstructed` | `(80, 4096)` |

حداکثر rank داده train پس از مرکزسازی `n_train - 1 = 319` است.

3. فقط همان کار را تغییر دهید.
